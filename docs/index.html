What it does

Press Ctrl Alt L and ask your files.

Everything is indexed and searched on your PC. Your files never leave it.

Finds the slide, not just the file

Type banker's algorithm and Alfred opens the deadlocks lecture on slide 4, with the matching words highlighted. Word, PowerPoint, Excel, PDF (scans too), text, photos and video frames.

  • Keyword and meaning search together
  • Points to the page, slide, sheet rows or video timestamp
  • Enter opens it right there

Reads your photos and notes

Ask what's coming in the DBMS mid-sem and Alfred finds the photo of a sticky note, because it reads the handwriting inside it. The note never uses the word "coming".

  • Text in pictures and scans is read on your PC
  • Search by meaning, not only exact words
  • Weak matches stay behind "Show weaker matches"

Shows you both versions

Two fee sheets, two different prices. Alfred lists both files with their dates, so you can see which one is current before you rely on a number.

  • Every result names its file and location
  • Ask Alfred answers with citations
  • Uses your Claude or ChatGPT plan, or an API key

For AI tools

Let Claude Code search your files too.

Alfred has a built-in MCP server. Claude Code, Codex, Claude Desktop, Cursor, VS Code, Windsurf and Gemini CLI connect with one click in Settings → AI tools.

Read-only

search_files, read_passage and search_code (code by meaning, name and callers), and only for folders you track.

You stay in charge

Alfred asks you before each tool's first search, and logs every call.

Checked before "Connected"

Alfred starts the server the way your tool will and checks that it answers.

  1. 1
    Unzip the whole folder anywhere you like. Keep Alfred.exe next to its _internal folder.
  2. 2
    Double-click Alfred.exe. This build isn't signed yet, so Windows may show "Windows protected your PC". Click More info, then Run anyway.
  3. 3
    Follow the setup steps: pick the folders to search, then try Ctrl Alt L.

Search by meaning is included. The zip comes with the EmbeddingGemma 2 search model and the llama.cpp engine, so search by name, text and meaning all work the first time you open Alfred, with nothing else to download. Finding photos by what they show needs one optional extra file (about 1 GB), which Alfred offers in Settings.
